# --- carried into the model for a consumer that does not read it ----------
#
# These cross a repository boundary, so no census confined to one repo can

# `sub_endpoints` and — since PR #601 — `node_concurrency`, `max_jitter_ms`
# and `miss`. The three below are what it still does not read.

# instead of a `reentrant` singleton per callback. The seam phase 68 W5
# opened is closed on both sides — and the census is what noticed, because
